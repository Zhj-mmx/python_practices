**和顺序表对比学习**

## 🎯 核心概念

### 什么是链表？

- 元素在内存中**不连续存储**
- 每个节点包含：**数据 + 指针（指向下一个节点）**
- 访问需要遍历（O(n)），但插入删除快（O(1)）

### 内存示意图

```
顺序表：┌─────┬─────┬─────┬─────┬─────┐
        │  A  │  B  │  C  │  D  │  E  │  连续存储
        └─────┴─────┴─────┴─────┴─────┘

链表：   A → B → C → D → E → None
        ┌───┐  ┌───┐  ┌───┐  ┌───┐  ┌───┐
        │data│  │data│  │data│  │data│  │data│
        │next┼─→│next┼─→│next┼─→│next┼─→│None│
        └───┘  └───┘  └───┘  └───┘  └───┘
        分散存储，通过指针连接
```

---

## 📊 顺序表 vs 链表

| 操作 | 顺序表 (list) | 链表 |
|------|--------------|------|
| 访问第 k 个元素 | O(1) ✅ | O(n) ❌ |
| 头部插入 | O(n) ❌ | O(1) ✅ |
| 中间插入 | O(n) ❌ | O(1) ✅ |
| 尾部插入 | O(1) ✅ | O(n) 或 O(1)* |
| 内存占用 | 紧凑 | 额外指针开销 |

*如果有尾指针

## 🔧 单链表实现

### 节点定义

```python
class Node:
    def __init__(self, data):
        self.data = data    # 数据
        self.next = None    # 指向下一个节点
```

### 链表定义

```python
class LinkedList:
    def __init__(self):
        self.head = None    # 头节点
    
    # 头部插入
    def insert_at_head(self, data):
        new_node = Node(data)
        new_node.next = self.head
        self.head = new_node
    
    # 尾部插入
    def insert_at_tail(self, data):
        new_node = Node(data)
        if self.head is None:
            self.head = new_node
            return
        
        # 遍历到最后一个节点
        current = self.head
        while current.next:
            current = current.next
        current.next = new_node
    
    # 查找
    def search(self, target):
        current = self.head
        while current:
            if current.data == target:
                return True
            current = current.next
        return False
    
    # 删除
    def delete(self, target):
        if self.head is None:
            return
        
        # 删除头节点
        if self.head.data == target:
            self.head = self.head.next
            return
        
        # 遍历查找
        current = self.head
        while current.next:
            if current.next.data == target:
                current.next = current.next.next
                return
            current = current.next
    
    # 打印链表
    def display(self):
        current = self.head
        elements = []
        while current:
            elements.append(str(current.data))
            current = current.next
        print(" → ".join(elements) + " → None")
```

## 💡 使用场景

### 用顺序表（list）
- 需要频繁随机访问
- 数据量已知或变化不大
- **Python 中 90% 的情况**

### 用链表
- 频繁在头部/中间插入删除
- 实现栈、队列、哈希表冲突解决
- 学习数据结构原理

## ⚠️ 注意事项

1. **小心空指针** - 访问 `node.next` 前先检查 `node` 是否为 `None`
2. **断链问题** - 插入删除时注意不要丢失后续节点
3. **Python 中很少手写链表** - list 足够好用，但理解链表对学其他数据结构很重要
