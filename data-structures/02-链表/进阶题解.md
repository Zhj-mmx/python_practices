## 【练习 2】反转链表 II - 参考答案

```python
def reverse_between(head, left, right):
    if not head or left == right:
        return head
    
    # dummy 节点，处理 left=1 的边界情况
    dummy = Node(0)
    dummy.next = head
    
    # 步骤 1：找到第 left-1 个节点（prev）
    prev = dummy
    for _ in range(left - 1):
        prev = prev.next
    
    # start 是第 left 个节点，反转后变成尾
    start = prev.next
    
    # 步骤 2：反转 [left, right] 区间
    # 需要反转 right - left 次
    curr = start.next
    for _ in range(right - left):
        # 把 curr 移到 start 前面
        start.next = curr.next      # start 跳过 curr
        curr.next = prev.next       # curr 指向 prev 的下一个（新的头）
        prev.next = curr            # prev 连接 curr（curr 成为新头）
        curr = start.next           # curr 前移
    
    return dummy.next
```

### 图解关键步骤

```
原链表：1 → 2 → 3 → 4 → 5, left=2, right=4

步骤 1：定位
dummy → 1 → 2 → 3 → 4 → 5
        ↑    ↑    ↑
      prev  start  curr

步骤 2：第一次反转（curr=3 移到 start 前面）
dummy → 1 → 3 → 2 → 4 → 5
        ↑         ↑    ↑
      prev       start  curr

步骤 3：第二次反转（curr=4 移到 start 前面）
dummy → 1 → 4 → 3 → 2 → 5
        ↑              ↑    ↑
      prev            start  curr

完成！返回 dummy.next
```

### 关键点

1. **dummy 节点**：当 left=1 时，头节点会变化
2. **反转次数**：`right - left` 次
3. **连接逻辑**：
   - `prev.next` 始终指向当前反转后的头
   - `start.next` 始终指向还未反转的部分
4. **一定要画图！**

## 【练习 3】K 个一组反转 - 参考答案

### 递归版（推荐！）

```python
def reverse_k_group(head, k):
    if not head or k == 1:
        return head
    
    # 步骤 1：检查剩余节点是否足够 k 个
    count = 0
    curr = head
    while curr and count < k:
        curr = curr.next
        count += 1
    
    # 不足 k 个，直接返回（不反转）
    if count < k:
        return head
    
    # 步骤 2：反转前 k 个节点
    prev = None
    curr = head
    for _ in range(k):
        next_temp = curr.next
        curr.next = prev
        prev = curr
        curr = next_temp
    
    # 此时 prev 是新的头，head 是新的尾
    # 步骤 3：递归处理剩余部分，并连接
    head.next = reverse_k_group(curr, k)
    
    return prev  # 返回新的头
```

### 迭代版（挑战！）

```python
def reverse_k_group(head, k):
    if not head or k == 1:
        return head
    
    dummy = Node(0)
    dummy.next = head
    prev_group = dummy
    
    while True:
        # 步骤 1：检查是否足够 k 个
        kth = prev_group
        for _ in range(k):
            kth = kth.next
            if not kth:
                return dummy.next  # 不足 k 个，结束
        
        group_next = kth.next  # 下一组的头
        
        # 步骤 2：反转当前组
        prev = group_next  # 反转后的尾要连接下一组
        curr = prev_group.next  # 当前组的头
        
        for _ in range(k):
            next_temp = curr.next
            curr.next = prev
            prev = curr
            curr = next_temp
        
        # 步骤 3：连接前后
        temp = prev_group.next
        prev_group.next = kth  # 前一组连接当前组的新头
        prev_group = temp  # 更新 prev_group 为当前组的尾
    
    return dummy.next
```

### 递归版图解

```
链表：1 → 2 → 3 → 4 → 5, k = 2

第一层递归：
  检查：1→2 足够 2 个 ✓
  反转前 2 个：2 → 1
  递归：head.next = reverse_k_group(3→4→5, 2)
  
第二层递归：
  检查：3→4 足够 2 个 ✓
  反转前 2 个：4 → 3
  递归：head.next = reverse_k_group(5, 2)
  
第三层递归：
  检查：5 只有 1 个，不足 2 个 ✗
  返回：5（不变）
  
连接回去：
  第二层：3 → 5，返回 4 → 3 → 5
  第一层：1 → (4 → 3 → 5)，返回 2 → 1 → 4 → 3 → 5
```

### 关键点

1. **先检查再反转**：不足 k 个时直接返回
2. **递归版更简洁**：核心就 3 步
3. **迭代版注意**：`prev` 初始化为 `group_next`，这样尾节点会自动连接下一组
4. **k=1 的情况**：直接返回，不需要反转
