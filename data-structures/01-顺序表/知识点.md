# 📚 顺序表（Sequential List）

**Python 中的顺序表 = `list`**

---

## 🎯 核心概念

### 什么是顺序表？

- 元素在内存中**连续存储**
- 通过**索引**快速访问（O(1)）
- Python 的 `list` 就是动态顺序表

### 内存示意图

```
索引：   0      1      2      3      4
       ┌──────┬──────┬──────┬──────┬──────┐
数据： │ 25.3 │ 26.1 │ 24.8 │ 25.5 │ 25.0 │
       └──────┴──────┴──────┴──────┴──────┘
       连续存储，每个元素占固定空间
```

---

## 🔧 基础操作

### 1. 创建列表

```python
# 空列表
lst = []
lst = list()

# 带初始值
lst = [1, 2, 3, 4, 5]
lst = [25.3, 26.1, 24.8]  # 小鼠体重数据

# 列表推导式（超实用！）
squares = [x**2 for x in range(5)]  # [0, 1, 4, 9, 16]
```

### 2. 访问元素

```python
lst = [10, 20, 30, 40, 50]

# 正向索引
print(lst[0])   # 10
print(lst[2])   # 30

# 负向索引（从后往前）
print(lst[-1])  # 50
print(lst[-2])  # 40

# 切片
print(lst[1:3])   # [20, 30]
print(lst[:3])    # [10, 20, 30]
print(lst[3:])    # [40, 50]
print(lst[::2])   # [10, 30, 50] 隔一个取一个
```

### 3. 增删改

```python
lst = [10, 20, 30]

# 增
lst.append(40)        # 末尾添加：[10, 20, 30, 40]
lst.insert(1, 15)     # 指定位置插入：[10, 15, 20, 30, 40]
lst.extend([50, 60])  # 扩展：[10, 15, 20, 30, 40, 50, 60]

# 删
lst.pop()             # 删除末尾，返回 60
lst.pop(0)            # 删除索引 0，返回 10
lst.remove(20)        # 删除值为 20 的元素

# 改
lst[0] = 100          # 修改索引 0 的值
```

### 4. 常用方法

```python
lst = [3, 1, 4, 1, 5, 9, 2, 6]

len(lst)          # 长度：8
lst.index(4)      # 查找值 4 的索引：2
lst.count(1)      # 统计 1 出现的次数：2
lst.sort()        # 排序：[1, 1, 2, 3, 4, 5, 6, 9]
lst.reverse()     # 反转：[6, 9, 5, 4, 3, 2, 1, 1]
min(lst)          # 最小值：1
max(lst)          # 最大值：9
sum(lst)          # 求和：31
```

## 💡 实战技巧

### 列表推导式（必学！）

```python
# 传统写法
squares = []
for x in range(10):
    squares.append(x**2)

# 列表推导式（一行搞定）
squares = [x**2 for x in range(10)]

# 带条件过滤
evens = [x for x in range(20) if x % 2 == 0]

# 嵌套推导式
matrix = [[i*j for j in range(3)] for i in range(3)]
# [[0, 0, 0], [0, 1, 2], [0, 2, 4]]
```

### 解包（Unpacking）

```python
# 基础解包
a, b, c = [1, 2, 3]

# 星号解包
first, *middle, last = [1, 2, 3, 4, 5]
# first=1, middle=[2,3,4], last=5
```

## ⚠️ 注意事项

1. **列表是可变对象** - 修改会影响原列表
2. **浅拷贝 vs 深拷贝** - `lst[:]` 是浅拷贝
3. **不要在遍历中删除元素** - 会出错！

```python
# 错误示范 ❌
for x in lst:
    if x % 2 == 0:
        lst.remove(x)  # 可能跳过元素！

# 正确做法 ✅
lst = [x for x in lst if x % 2 != 0]
```
