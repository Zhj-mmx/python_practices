# 基础代码练习：哈夫曼树的构造与编码

## 练习目标
- 掌握哈夫曼树的贪心构造过程。
- 能够用代码实现从权值集合构建哈夫曼树。
- 能够根据哈夫曼树生成每个叶子节点的二进制编码。
- 理解并验证哈夫曼编码的前缀码特性与最优性。

## 问题描述

给定 **n 个字符**及其对应的**出现频率（权值）**，请构造一棵哈夫曼树，并输出每个字符的哈夫曼编码。

### 输入格式
- 第一行：一个整数 n (1 ≤ n ≤ 100)，表示字符个数。
- 接下来 n 行：每行一个字符（单个小写字母或数字）和一个整数 w (1 ≤ w ≤ 1000)，表示该字符的频率。

> 保证字符不重复。

### 输出格式
- 输出 n 行，每行格式为：`字符: 编码`
- 编码为 0/1 字符串，按**任意合法哈夫曼树**输出即可（如果有多棵哈夫曼树，输出任意一棵对应的编码）。
- 要求：**左分支为 '0'，右分支为 '1'**（若某内部节点左右子树权值相等，可任意分配）。

### 示例

**输入**：
```
4
a 5
b 3
c 2
d 1
```

**可能的输出**（注意：不唯一）：
```
a: 1
b: 01
c: 001
d: 000
```
