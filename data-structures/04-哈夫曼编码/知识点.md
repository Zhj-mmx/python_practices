# 哈夫曼树（Huffman Tree）基础知识讲解

## 一、为什么需要哈夫曼树？

在日常数据处理中，我们经常遇到“不同数据出现频率不同”的情况。例如：
- 英文字母 `e` 出现的频率远高于 `z`
- 一段文字中，某些词语重复多次
- 一个文件里，不同字节的值出现的次数差异很大

如果给所有数据分配**相同长度**的编码（比如 ASCII 每个字符 8 位），那么高频数据和低频数据占用相同空间，造成浪费。  
**哈夫曼树**的目标就是：**让出现频率高的数据用更短的编码，频率低的数据用较长的编码**，从而整体上缩短总长度（即实现数据压缩）。

---

## 二、基本概念

### 1. 权值（Weight）
- 给每个叶子节点赋予一个数值，代表该节点出现的频率、概率、重量等。
- 例如：字符 `a` 出现 5 次，则其权值可设为 5。

### 2. 路径长度（Path Length）
- 从根节点到某个节点经过的边的数量。

### 3. 带权路径长度（Weighted Path Length, WPL）
- 所有叶子节点的 **权值 × 该叶子到根的路径长度** 之和。
- 公式：  
  \[
  WPL = \sum_{i=1}^{n} (w_i \times l_i)
  \]
  其中 \(w_i\) 为第 i 个叶子节点的权值，\(l_i\) 为根到该叶子的路径长度。

### 4. 哈夫曼树（最优二叉树）
- 给定 n 个权值作为 n 个叶子节点，构造一棵二叉树，使得该树的 **WPL 最小**，这样的二叉树称为哈夫曼树。

---

## 三、哈夫曼树的构造过程（贪心算法）

**输入**：n 个权值 \(\{w_1, w_2, ..., w_n\}\)  
**输出**：一棵哈夫曼树

**步骤**：
1. 将每个权值看作一个只有根节点（无左右孩子）的二叉树，这些树构成一个**森林**。
2. 从森林中选出 **权值最小** 和 **次小** 的两棵树，作为左右子树，构建一棵新的二叉树：
   - 新树的根节点权值 = 左右子树根节点权值之和
   - 左右子树分别为选出的两棵树
3. 从森林中删除这两棵树，并将新树加入森林。
4. 重复步骤 2~3，直到森林中只剩下一棵树。这棵树就是哈夫曼树。

> **注意**：当两个最小权值相等时，可以任意选择顺序，不影响 WPL 的最小性，但可能会产生不同形状的树。

**举例**：权值集合 {5, 3, 2, 1}
- 初始：5, 3, 2, 1
- 选最小 1 和 2，合并为 (3)，新森林 {5, 3, 3}
- 选最小 3 和 3，合并为 (6)，新森林 {5, 6}
- 选最小 5 和 6，合并为 (11)，结束。
得到的哈夫曼树 WPL = 1×3 + 2×3 + 3×2 + 5×1 = 3+6+6+5 = 20

## 四、哈夫曼编码（Huffman Coding）

### 1. 基本思想
- 利用哈夫曼树为每个字符生成 **二进制编码**。
- 约定：从根出发，**向左走为 0，向右走为 1**（也可相反）。
- 到达某个叶子节点所经过的路径上的 0/1 序列，即为该叶子对应字符的编码。

### 2. 重要性质
- **前缀码**：任何字符的编码都不是另一个字符编码的前缀。这保证了解码时不会产生歧义。
- **最优性**：在所有前缀码中，哈夫曼编码得到的平均长度最短（即总编码长度最小）。

### 3. 示例
字符频率：A(5), B(3), C(2), D(1)  
构造哈夫曼树（略，与上例相同），假设左0右1：
- D(1): 路径 左-左-左 → 000
- C(2): 左-左-右 → 001
- B(3): 左-右 → 01
- A(5): 右 → 1

总编码长度 = 5×1 + 3×2 + 2×3 + 1×3 = 5+6+6+3 = 20 位。  
如果用等长编码（2位），则总长度 = (5+3+2+1)×2 = 22 位，哈夫曼编码节省了 2 位。

## 五、哈夫曼树的重要性质

1. **没有度为 1 的节点**（满二叉树性质）：  
   哈夫曼树中除了叶子节点，所有内部节点都有两个子节点（因为每次合并两棵树）。所以若叶子节点数为 n，则总结点数为 2n-1。

2. **权值越大的叶子离根越近**，路径长度越小。

3. **WPL 最小**：在所有以相同权值为叶子的二叉树中，哈夫曼树的 WPL 最小。

4. **构造不唯一**：当最小权值有多个时，合并顺序不同会产生不同形状的树，但所有哈夫曼树的 WPL 相同。

## 六、哈夫曼树的应用

| 应用领域 | 说明 |
|---------|------|
| 文件压缩 | ZIP, GZIP, JPEG（部分步骤）等使用哈夫曼编码 |
| 通信编码 | 如传真、视频编码中的熵编码 |
| 最优合并问题 | 例如“合并石子最小代价”问题 |
| 决策树优化 | 在加权情况下最小化平均查找/比较次数 |

---

## 七、与其它树的对比

| 树类型 | 主要特点 | 应用 |
|--------|----------|------|
| 二叉搜索树 | 左<根<右，快速查找 | 数据存储与检索 |
| 堆 | 完全二叉树，父节点 ≤ 子节点 | 优先队列 |
| **哈夫曼树** | 带权路径最小 | 数据压缩、最优合并 |

---

## 八、总结

- 哈夫曼树通过**贪心策略**构造，每次合并最小权值节点。
- 它使 **WPL 最小**，从而实现高效编码或最小合并代价。
- 哈夫曼编码是一种**最优前缀码**，广泛应用于无损压缩。
- 掌握哈夫曼树是理解数据压缩、贪心算法和二叉树应用的重要基础。
