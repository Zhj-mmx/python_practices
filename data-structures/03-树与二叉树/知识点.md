# 🌳 树与二叉树（Tree & Binary Tree）

**非线性数据结构的起点！**

---

## 🎯 核心概念

### 什么是树？

- **树（Tree）**：由节点（node）组成的层次结构
- **根节点（Root）**：树的最顶层节点（没有父节点）
- **叶子节点（Leaf）**：没有子节点的节点
- **父节点/子节点**：上下层关系

```
        A           ← 根节点
       / \
      B   C         ← 子节点
     / \   \
    D   E   F       ← D、E、F 是叶子节点
    
    高度 = 3（从根到最远叶子的层数）
```

### 什么是二叉树？

**每个节点最多有两个子节点**（左子树 + 右子树）

```
        1
       / \
      2   3
     / \   \
    4   5   6
    
    ✓ 这是二叉树（每个节点最多 2 个子节点）
```

### 特殊二叉树

| 类型 | 特点 |
|------|------|
| **满二叉树** | 所有层都填满，叶子都在同一层 |
| **完全二叉树** | 除了最后一层，其他层都填满；最后一层从左到右连续 |
| **二叉搜索树 (BST)** | 左子树 < 根 < 右子树 |

```
满二叉树：      完全二叉树：    二叉搜索树：
    1               1               4
   / \             / \             / \
  2   3           2   3           2   6
 / \ / \         / \ /           / \ / \
4  5 6  7       4  5 6          1  3 5  7
✓ 所有层填满    ✓ 最后一层从左连续  ✓ 左<根<右
```

---

## 📊 重要性质

### 二叉树的性质

1. **第 i 层最多有 2^(i-1) 个节点**（i≥1）
2. **高度为 h 的二叉树最多有 2^h - 1 个节点**
3. **叶子节点数 = 度为 2 的节点数 + 1**

### 时间复杂度对比

| 操作 | 顺序表 | 链表 | 二叉搜索树 |
|------|--------|------|-----------|
| 查找 | O(1) | O(n) | O(log n)* |
| 插入 | O(n) | O(1) | O(log n)* |
| 删除 | O(n) | O(1) | O(log n)* |

*平衡树的情况下，最坏 O(n)

## 🔧 二叉树实现

### 节点定义

```python
class TreeNode:
    def __init__(self, val):
        self.val = val
        self.left = None   # 左子节点
        self.right = None  # 右子节点
```

### 二叉树定义

```python
class BinaryTree:
    def __init__(self):
        self.root = None
    
    # 插入（二叉搜索树规则）
    def insert(self, val):
        if self.root is None:
            self.root = TreeNode(val)
        else:
            self._insert_helper(self.root, val)
    
    def _insert_helper(self, node, val):
        if val < node.val:
            if node.left is None:
                node.left = TreeNode(val)
            else:
                self._insert_helper(node.left, val)
        else:
            if node.right is None:
                node.right = TreeNode(val)
            else:
                self._insert_helper(node.right, val)
    
    # 查找
    def search(self, val):
        return self._search_helper(self.root, val)
    
    def _search_helper(self, node, val):
        if node is None:
            return False
        if node.val == val:
            return True
        if val < node.val:
            return self._search_helper(node.left, val)
        else:
            return self._search_helper(node.right, val)
    
    # 前序遍历（根→左→右） 又叫先序遍历
    def preorder(self, node):
        if node is None:
            return []
        return [node.val] + self.preorder(node.left) + self.preorder(node.right)
    
    # 中序遍历（左→根→右）- BST 中序是有序的！
    def inorder(self, node):
        if node is None:
            return []
        return self.inorder(node.left) + [node.val] + self.inorder(node.right)
    
    # 后序遍历（左→右→根）
    def postorder(self, node):
        if node is None:
            return []
        return self.postorder(node.left) + self.postorder(node.right) + [node.val]
    
    # 层序遍历（BFS）
    def level_order(self):
        if self.root is None:
            return []
        
        result = []
        queue = [self.root]
        
        while queue:
            node = queue.pop(0)
            result.append(node.val)
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        
        return result
    
    # 获取树的高度
    def get_height(self, node):
        if node is None:
            return 0
        return 1 + max(self.get_height(node.left), self.get_height(node.right))
```

## 🎯 三种遍历方式（必考！）

### 前序遍历（Preorder）- 根左右

```
    1
   / \
  2   3
 / \
4   5

前序：1 → 2 → 4 → 5 → 3
```

### 中序遍历（Inorder）- 左根右

```
    1
   / \
  2   3
 / \
4   5

中序：4 → 2 → 5 → 1 → 3

💡 BST 的中序遍历是有序的！
```

### 后序遍历（Postorder）- 左右根

```
    1
   / \
  2   3
 / \
4   5

后序：4 → 5 → 2 → 3 → 1
```

### 层序遍历（Level Order）- BFS

```
    1
   / \
  2   3
 / \
4   5

层序：1 → 2 → 3 → 4 → 5
```

## 💡 使用场景

### 二叉搜索树（BST）
- 需要快速查找、插入、删除
- 数据需要保持有序
- 实现字典、集合等数据结构

### 堆（Heap）
- 优先队列
- Top K 问题
- 堆排序

### 哈夫曼树
- 数据压缩
- 编码优化

### 表达式树
- 编译器解析表达式
- 计算表达式值

## ⚠️ 注意事项

1. **递归是核心** - 树的操作大多用递归
2. **注意空节点** - 访问 `node.left` 前先检查 `node` 是否为 `None`
3. **BST 可能退化** - 如果插入有序数据，BST 会退化成链表（O(n)）
4. **Python 中用 dict 更多** - 但理解树对学习其他算法很重要
