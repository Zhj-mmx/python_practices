# 小鼠 cart 肽疗法响应预测 - 建模思路详解

## 📋 项目概述

### 研究背景
- **课题**：用机器学习预测小鼠对 cart 肽疗法的响应
- **数据来源**：医学院合作课题，行为学实验 + WB 蛋白表达
- **样本量**：20 只小鼠（5 组 × 4 只/组）
- **任务类型**：二分类（适合/不适合疗法）

### 核心挑战
```
⚠️ 小样本 (n=20, 可用训练样本仅 8 个)
⚠️ 特征相对多 (7 个原始特征)
⚠️ 需要医学可解释性
⚠️ 容易过拟合
```

## 📊 第一步：数据理解

### 原始数据结构
| 列名 | 类型 | 说明 |
|------|------|------|
| 类别 | 分类 | 对照组、急性戒断、慢性戒断、急性+cart、慢性+cart |
| 活动度 | 数值 | 旷场实验总活动距离 |
| 中央次数 | 数值 | 进入中央区域次数 |
| 中央时间 | 数值 | 在中央区域停留时间 |
| 开臂次数 | 数值 | 高架十字迷宫开臂进入次数 |
| 开臂时间 | 数值 | 在开臂停留时间（焦虑指标） |
| gb1 表达量 | 数值 | 蛋白表达水平 |
| gb2 表达量 | 数值 | 蛋白表达水平 |

### 各组样本
```
对照组：4 只   → 基线，不用于训练
急性戒断：4 只 → 模型比较基线，不用于训练
慢性戒断：4 只 → 模型比较基线，不用于训练
急性+cart：4 只 → 训练样本（需要打标签）
慢性+cart：4 只 → 训练样本（需要打标签）
```

**可用训练样本：8 个**

## 🏷️ 第二步：标签定义

### 判定标准
根据课题组标准：
- **焦虑改善 ≥ 30%**
- **行为敏化改善 ≥ 40%**
- **两者同时满足 = 适合疗法 (1)**

### 计算公式
```python
# 焦虑改善率 = (cart 组开臂时间 - 戒断组开臂时间) / 戒断组开臂时间
# 行为改善率 = (戒断组活动度 - cart 组活动度) / 戒断组活动度

# 注意：行为改善是"降低"，因为戒断后活动度升高是病理表现
```

### 示例计算
```
急性戒断组基线：
  - 开臂时间：138.81s (均值)
  - 活动度：3240 (均值)

急性+cart 某小鼠：
  - 开臂时间：161.24s
  - 活动度：654

焦虑改善率 = (161.24 - 138.81) / 138.81 = 16.2%  (< 30%, 不达标)
行为改善率 = (3240 - 654) / 3240 = 80.1%  (> 40%, 达标)

→ 标签 = 0 (不适合，因为焦虑改善未达标)
```

## 🔧 第三步：特征工程

### 特征选择原则
**小样本下，特征越少越好！**

### 推荐特征（4 个）
| 特征 | 理由 |
|------|------|
| 活动度 | 行为敏化核心指标 |
| 开臂时间 | 焦虑核心指标 |
| gb1 表达量 | 关键蛋白，假设与响应相关 |
| gb2 表达量 | 关键蛋白 |

### 衍生特征（可选，谨慎添加）
```python
# 1. 蛋白比值
gb1_gb2_ratio = gb1 / gb2

# 2. 焦虑指数
焦虑指数 = 开臂时间 / 开臂次数

# 3. 单位活动开臂
单位活动开臂 = 开臂时间 / 活动度
```

**建议**：先用 4 个原始特征，如果效果不好再考虑衍生特征。

## 🤖 第四步：模型选择

### 候选模型对比
| 模型 | 优点 | 缺点 | 推荐度 |
|------|------|------|--------|
| **逻辑回归** | 简单、可解释、不易过拟合 | 只能捕捉线性关系 | ⭐⭐⭐⭐⭐ |
| **SVM (线性)** | 小样本表现好、理论保证 | 调参敏感 | ⭐⭐⭐⭐ |
| **随机森林** | 可处理非线性、输出重要性 | 容易过拟合 | ⭐⭐⭐ |
| XGBoost | 强大 | 需要更多数据 | ❌ 不推荐 |

### 推荐配置
```python
# 主模型：逻辑回归
LogisticRegression(C=1.0, penalty='l2', solver='lbfgs')

# 备选：SVM
SVC(kernel='linear', C=1.0, probability=True)

# 备选：随机森林（限制复杂度）
RandomForestClassifier(n_estimators=5, max_depth=2, min_samples_leaf=2)
```

## ✅ 第五步：验证策略

### 为什么不能用常规 train/test split？
```
8 个样本，如果 7:1 分割：
  - 训练集 7 个，测试集 1 个
  - 测试结果高度依赖那 1 个样本
  - 无法可靠评估性能
```

### 推荐：留一法交叉验证 (LOOCV)
```
┌────────────────────────────────────────┐
│  迭代 1: 训练 [2,3,4,5,6,7,8], 测试 [1] │
│  迭代 2: 训练 [1,3,4,5,6,7,8], 测试 [2] │
│  ...                                   │
│  迭代 8: 训练 [1,2,3,4,5,6,7], 测试 [8] │
└────────────────────────────────────────┘

最终指标 = 8 次测试结果的平均
```

### 评估指标
- **准确率**：整体正确率
- **AUC-ROC**：判别能力（小样本下可能不稳定）
- **灵敏度**：真正例率（识别出适合疗法的比例）
- **特异度**：真负例率（识别出不适合疗法的比例）

## 🛡️ 第六步：防止过拟合

### 过拟合风险
```
8 个样本，7 个特征 → 几乎必然过拟合！
```

### 防护措施
```python
# 1. 特征选择
只保留 3-4 个最有意义的特征

# 2. 正则化
逻辑回归用 L2 正则 (C=0.1~1.0)

# 3. 数据标准化
StandardScaler()  # 必须做！

# 4. 限制模型复杂度
随机森林：max_depth=2, n_estimators=5

# 5. 交叉验证
LOOCV 评估，不用测试集（样本太少）
```

## 📈 第七步：可解释性

### 医学论文需要的解释

#### 1. 特征重要性
```python

coef = model.coef_[0]
# 系数为正 → 该特征值越大，越可能适合疗法
# 系数为负 → 该特征值越大，越可能不适合疗法
```

#### 2. 判定规则（简化版）
```
示例输出：
Logit(P) = -2.345
  + 1.234 × gb1 表达量
  - 0.567 × 活动度
  + 0.890 × 开臂时间
  - 0.123 × gb2 表达量

解释：
- gb1 表达量越高，越可能适合疗法
- 活动度越低（行为改善越好），越可能适合疗法
```

## 💡 常见问题

### Q1: 为什么 AUC 置信区间这么宽？
**A**: 样本量小导致估计不稳定。8 个样本的 AUC 置信区间通常很宽，这是正常的。重点看点估计和效应方向。

### Q2: 逻辑回归和随机森林结果不一致怎么办？
**A**: 优先相信逻辑回归。小样本下复杂模型容易过拟合，简单模型更可靠。

### Q3: 能否用深度学习？
**A**: 绝对不能。深度学习需要大量数据，8 个样本会严重过拟合。

### Q4: 如何改进模型？
**A**: 
1. 收集更多数据（最重要！）
2. 利用先验知识做特征选择
3. 考虑贝叶斯方法（引入先验分布）
4. 与类似研究做 Meta 分析
