例题 1：股票收益率计算
题目描述：
假设你有某股票连续 5 天的收盘价数组：[100, 102, 101, 105, 107]。
请计算每日的简单收益率（公式：(今日价 - 昨日价) / 昨日价），结果保留 4 位小数。
提示：使用切片和向量化运算，不要用循环。

<details> <summary><b>点击查看答案与解析</b></summary>
python
import numpy as np

prices = np.array([100, 102, 101, 105, 107])

# 解法：利用切片错位相减
# prices[1:] 从第二天开始取；prices[:-1] 从第一天取到倒数第二天
returns = (prices[1:] - prices[:-1]) / prices[:-1]
returns = np.round(returns, 4)

print("每日收益率:", returns)
输出：

text
每日收益率: [ 0.02   -0.0098  0.0396  0.019 ]

例题 2：数据归一化 (Z-Score 标准化)
题目描述：
给定一个 3x3 的随机整数矩阵 data，值范围在 1~100 之间。请对每一列分别进行 Z-Score 标准化，即 (x - 列均值) / 列标准差。要求输出标准化后的矩阵，并验证每列的均值接近于 0，标准差接近于 1。

<details> <summary><b>点击查看答案与解析</b></summary>
python
np.random.seed(42)  # 固定随机种子方便复现
data = np.random.randint(1, 100, size=(3, 3))
print("原始数据:\n", data)

# 计算每列的均值和标准差 (axis=0 表示按列操作)
mean_col = data.mean(axis=0)
std_col = data.std(axis=0)

# 标准化 (利用广播)
normalized = (data - mean_col) / std_col

print("\n标准化后数据:\n", normalized.round(4))

# 验证
print("\n新均值 (接近0):", normalized.mean(axis=0).round(6))
print("新标准差 (接近1):", normalized.std(axis=0).round(6))

例题 3：最近邻插值（KNN 思想）
题目描述：
有一组样本点 points 和待查询点 query。不使用循环，计算 query 到 points 中每个点的欧几里得距离，并找出距离最近的点索引及其距离值。
points = np.array([[1, 2], [3, 4], [5, 6], [7, 8]])
query = np.array([4, 5])

<details> <summary><b>点击查看答案与解析</b></summary>
python
points = np.array([[1, 2], [3, 4], [5, 6], [7, 8]])
query = np.array([4, 5])

# 向量化计算距离：利用广播求差值的平方和，再开方
diff = points - query                 # 广播：(4,2) - (2,) -> (4,2)
squared_dist = np.sum(diff ** 2, axis=1) # 按行求和
distances = np.sqrt(squared_dist)

# 找到最近邻索引
nearest_idx = np.argmin(distances)
nearest_dist = distances[nearest_idx]

print("各点距离:", distances)
print(f"最近点索引: {nearest_idx}, 坐标: {points[nearest_idx]}, 距离: {nearest_dist:.4f}")

例题 4：矩阵运算与线性方程组求解
题目描述：
求解线性方程组：

text
2x + 3y = 8
5x + 4y = 13
请用 NumPy 的线性代数模块 np.linalg.solve 求解，并验证解的正确性。

<details> <summary><b>点击查看答案与解析</b></summary>
python
# 系数矩阵 A
A = np.array([[2, 3],
              [5, 4]])

# 常数向量 b
b = np.array([8, 13])

# 求解 Ax = b
x = np.linalg.solve(A, b)
print("解向量 [x, y] =", x)

# 验证：计算 A @ x 是否等于 b
print("验证 A @ x =", A @ x)
