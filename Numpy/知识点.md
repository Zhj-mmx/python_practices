# NumPy 入门到精通练习手册（初中生友好版·知识点详解）

> **学习前的小提示**：你可以把 NumPy 想象成一个**超级计算器 + 乐高积木工厂**。它不仅能算数，还能把一堆数字像搭积木一样，拼成一行、一张表、甚至一个魔方，然后一下子就把所有积木块都算完了！

## 第一部分：核心知识点深度详解

### 1. 什么是 NumPy？

**通俗解释（初中生版）：**
想象一下，体育老师让你记录全班 50 个同学的身高。如果用普通的 Python 列表 `heights = [1.55, 1.60, ...]`，你想给每个人身高加 2 厘米（穿鞋量），你需要写一个 `for` 循环，一个一个地加，就像排队领书，一次只能发一个人。

**NumPy 的做法是：** 它把这 50 个身高数据变成一个**数字方块（数组）**。你只要说一句“全体加 2”，它就瞬间给 50 个数据同时加上 2，就像广播通知全班，所有人同时听到了，**速度快了不止一倍**，而且写代码只要一行。

**核心价值（为什么必须学）：**
- **速度快**：底层用 C 语言写的，比 Python 循环快几十倍。
- **省内存**：存储同样的数字，NumPy 用的内存比列表少得多。
- **写起来爽**：复杂的数学公式，一行代码搞定。

### 2. 数组的创建（从无到有变出数据）

在 NumPy 里，我们把数据叫做 **`ndarray`**（N-dimensional array，多维数组）。我们可以把它理解成：**一维是排队，二维是操场方阵，三维是教学楼（每层一个方阵）。**

| 函数名 | 功能通俗解释（初中生版） | 代码与注释 |
| :--- | :--- | :--- |
| `np.array()` | **手写名单**：你把现成的名单（列表）交给它，它帮你变成一个超级方阵。 | `a = np.array([1, 2, 3]) # 变成一排站好的 1, 2, 3` |
| `np.zeros()` | **空座位表**：给你一张全是 0 的表格，等着填数字。 | `b = np.zeros((2, 3)) # 2行3列的座位表，目前全是0分` |
| `np.ones()` | **全是满分表**：生成全是 1 的表格。 | `c = np.ones((3, 2)) # 3行2列，全是1（比如初始积分）` |
| `np.arange()` | **报数生成器**：像军训报数一样，从几开始，到几结束（不含），每次走几步。 | `d = np.arange(0, 10, 2) # 0, 2, 4, 6, 8` |
| `np.linspace()` | **切香肠**：告诉它头和尾，再告诉它要切几段，它自动算好均匀的距离。 | `e = np.linspace(0, 1, 5) # 0到1之间切4刀，变成5个点` |
| `np.random.rand()` | **摇骰子（小数）**：生成 0 到 1 之间的随机小数。 | `f = np.random.rand(2, 2) # 摇出一个2x2的随机小数阵` |
| `np.random.randint()` | **摇骰子（整数）**：生成指定范围的随机整数。 | `g = np.random.randint(1, 10, size=(3,3)) # 1到9的随机数填满3x3` |

### 3. 数组的属性（给数据方阵做“体检”）

拿到一个数组后，我们需要知道它长什么样、有多大。就像你拿到一盒积木，要先看看盒子上的标签：**几块积木？什么形状？什么材质？**

| 属性名 | 通俗解释（初中生版） | 注释示例 |
| :--- | :--- | :--- |

| `ndim` | **维度**。排队是 1 维，方阵是 2 维，魔方是 3 维。 | `arr.ndim # 这是几维空间的东西？` |

| `itemsize` | **饭量**。每个数字在电脑内存里占几个字节。 | `arr.itemsize # 每个数字吃多少内存` |

### 4. 索引与切片（精准定位数据）

就像在电影院找座位，或者在 Excel 里框选一片区域。**注意：NumPy 的行列是从 `0` 开始数的！**

| 操作方式 | 通俗解释（初中生版） | 代码注释 |
| :--- | :--- | :--- |
| **基础索引** | **找单个座位**：第几排第几座。 | `arr[2, 3] # 找第 3 排（索引2）第 4 座（索引3）的人` |
| **切片** | **框选区域**：第 1 排到第 3 排的所有人，只要第 2 列到第 4 列。 | `arr[0:3, 1:4] # 注意：后面的数是不包含的，像包饺子不包最后那个褶` |
| **布尔索引** | **点名筛选**：身高大于 170 的同学请起立。 | `arr[arr > 5] # 把方阵里所有大于 5 的数字挑出来，拉成一排` |
| **花式索引** | **点名册点名**：只叫第 0 号、第 3 号、第 5 号同学出来。 | `arr[[0, 3, 5]] # 不管顺序，指定谁谁出来` |

### 5. 通用函数（神奇的“全体魔法”）

这是 NumPy 最酷的地方。你不用写循环，直接对**整个数组**施魔法。

**比喻：** 普通的 Python 计算就像**喂鸡**，你手里一把米，要一粒一粒扔给鸡吃。NumPy 的通用函数就像**撒网**，一把米撒出去，所有的鸡同时吃到了。

| 分类 | 函数举例 | 通俗解释与注释 |
| :--- | :--- | :--- |
| **四则运算** | `np.add(x, y)` | 等价于 `x + y`，两队人对应握手相加。 |
| **科学运算** | `np.sqrt(arr)` | **开平方根**：给每个数找一个数，自己乘自己等于它。 |
| **指数对数** | `np.exp(arr)` | **疯狂生长**：计算 e (2.718...) 的多少次方。 |
| **三角函数** | `np.sin(arr)` | **波浪线**：输入角度，输出波浪高度。 |
| **统计函数** | `np.mean(arr)` | **求平均分**：把所有数加起来除以总人数。 |
| **极值函数** | `np.max(arr)`, `np.argmax(arr)` | **最高分是谁** / **最高分坐在第几个位置**。 |
| **累积求和** | `np.cumsum(arr)` | **存钱罐记录**：第一天存1块，第二天共存了 1+2=3 块，第三天共存 1+2+3=6 块... |

### 6. 广播机制（让不同形状的积木也能一起玩）

**核心痛点：** 如果 `A` 是 3行4列，`B` 只有 1行4列，怎么相加？

**初中生解释：** 你有一张全班成绩表（3行4列），你想给**每一行**都加上不同的**卷面分奖励**（比如语文+2分，数学+5分）。你不需要把奖励抄写 3 遍，NumPy 会自动把那个**只有 1 行的奖励**复制粘贴成 3 行，然后相加。

**规则口诀（背下来！）：**
1. 从最后一个维度比大小。
2. 如果两个形状**一样大**，或者其中一个是 **1**，就能一起算。
3. 那个是 **1** 的维度会被拉伸变大。

**例子：**
- `(3, 4)` 和 `(4,)` -> 能算。`(4,)` 被看成 `(1, 4)`，复制成 3 行。
- `(3, 4)` 和 `(3, 1)` -> 能算。`(3, 1)` 复制成 4 列。
- `(3, 4)` 和 `(3, 5)` -> **报错！** 最后维度 4 和 5 对不上，没法拉伸。

### 7. 形状操作（给数组变魔术、变形金刚）

| 操作 | 通俗解释（初中生版） | 代码注释 |
| :--- | :--- | :--- |
| `reshape()` | **重新排队**：本来排成一长队 12 个人，喊个口令变成 3 排 4 列的方阵。**总人数不能变**。 | `arr.reshape(3, 4) # 队形变换，人还是那些人` |
| `resize()` | **强制剪裁/补人**：如果人不够，就复制前面的人来凑；人多了就裁掉。 | `np.resize(arr, (3, 5)) # 改形状，数字不够就重复` |
| `flatten()` | **解散成一列纵队**：不管原来什么方阵，全部拉直排成一行。 | `arr.flatten() # 方阵变一长条` |
| `ravel()` | **也是拉直**，但更“省电”，不轻易复制新队伍。 | `arr.ravel() # 速度快，但改了它可能会影响原来的队伍` |
| `T` (Transpose) | **转置（对角线翻转）**：把行变成列，列变成行。就像把本子转 90 度看。 | `arr.T # 第1排变成第1列` |
| `hstack` | **左右拼接**：两个班级的队伍，左右挨着站在一起。 | `np.hstack((A, B)) # 行数必须一样` |
| `vstack` | **上下堆叠**：A 班站前面，B 班站后面。 | `np.vstack((A, B)) # 列数必须一样` |
