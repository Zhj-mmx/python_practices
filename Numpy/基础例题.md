### 练习题 1：创建特征矩阵（Features）和标签（Labels）

**场景故事：**
你要训练一个 AI 预测房价。你有 4 套房子，每套房有 3 个特征：`[面积(平米), 卧室数量, 房龄(年)]`。同时，你知道这 4 套房的实际成交价（标签）。

**任务要求：**
1. 创建一个 **4行3列** 的二维数组 `X`，数据如下：
   - 房子1: 120平米, 3室, 5年
   - 房子2: 85平米, 2室, 20年
   - 房子3: 200平米, 4室, 2年
   - 房子4: 60平米, 1室, 40年
2. 创建一个一维数组 `y`，代表对应的房价（单位：万元）：`[350, 180, 620, 90]`

```python
import numpy as np

# ========== 你的代码在这里 ==========
X = None  # 请替换这行
y = None  # 请替换这行
# ===================================

print("特征矩阵 X:\n", X)
print("标签向量 y:", y)
print("X 的形状应为 (4, 3)，实际为:", X.shape)
```

<details>
<summary><b>✅ 点击查看答案与解析</b></summary>

```python
import numpy as np

# 答案代码
X = np.array([
    [120,   3,  5],
    [ 85,   2, 20],
    [200,   4,  2],
    [ 60,   1, 40]
])

y = np.array([350, 180, 620, 90])

print("特征矩阵 X:\n", X)
print("标签向量 y:", y)
print("X 的形状应为 (4, 3)，实际为:", X.shape)
``` 

**解析（初中生版）：**
- **X 是特征矩阵**：就像 Excel 表格，行是“第几个样本”（第几套房），列是“有什么特点”（面积、几室、几年）。
- **y 是标签向量**：就是标准答案，AI 要学的目标。
- `np.array()` 外面套了一层 `[ ... ]`，里面每一套房子用 `[120, 3, 5]` 表示，记得用逗号隔开。
</details>

### 练习题 2：提取特定特征列（切片操作）

**场景故事：**
做数据分析时，你只想看看“面积”这一列对房价的影响，或者想看看前两套房子的“面积和卧室数”。

**任务要求：**
利用上一题的 `X` 数组，完成以下操作（**禁止直接手写数字，必须用切片/索引提取**）：
1. 提取所有房子的 **面积** 列（索引为 0 的那一列），存入 `area`。
2. 提取前两套房子的 **面积和卧室数**（前两行，前两列），存入 `subset`。

```python
# 接上一题代码，X 已经存在

# ========== 你的代码在这里 ==========
area = None      # 提示：要取所有行，第0列
subset = None    # 提示：行取 0 到 2 (不含2)，列取 0 到 2 (不含2)
# ===================================

print("所有房子的面积:", area)
print("前两套房子的面积和卧室数:\n", subset)
```

<details>
<summary><b>✅ 点击查看答案与解析</b></summary>

```python
# 答案代码
area = X[:, 0]        # 冒号 : 代表“所有行”，0 代表“第0列”
subset = X[:2, :2]    # 行：从0开始到2(不含)，列：从0开始到2(不含)

print("所有房子的面积:", area)
print("前两套房子的面积和卧室数:\n", subset)
```

**解析（初中生版）：**
- `X[:, 0]`：想象电影院座位，`:` 意思是“每一排的人我都叫起来”，`0` 意思是“只要第 0 号座位的人”。结果是一维数组 `[120, 85, 200, 60]`。
- `X[:2, :2]`：切左上角一块肉。行取 0,1；列取 0,1。结果是 `[[120, 3], [85, 2]]`。
</details>

### 练习题 3：数据过滤（布尔索引）

**场景故事：**
机器学习中经常需要**剔除异常值**或**筛选感兴趣的数据**。比如，你想专门研究“房龄大于 10 年的老房子”的房价规律，或者把房价高于 200 万的豪宅挑出来。

**任务要求：**
1. 从 `X` 中找出所有 **房龄大于 10 年** 的房子特征（房龄是第 2 列，索引为 2）。
2. 从 `y` 中找出 **房价高于 200 万** 的标签。

```python
# 接前文，X 和 y 已存在

# ========== 你的代码在这里 ==========
old_house_X = None    # 提示：用布尔索引 X[:, 2] > 10
expensive_y = None    # 提示：直接对 y 用布尔索引
# ===================================

print("老房子特征:\n", old_house_X)
print("豪宅价格:", expensive_y)
```

<details>
<summary><b>✅ 点击查看答案与解析</b></summary>

```python
# 答案代码
# 1. 先拿到“是否老房子”的布尔序列
is_old = X[:, 2] > 10           # [False, True, False, True]
old_house_X = X[is_old]         # 把对应 True 的行抽出来

# 或者直接一行搞定：
# old_house_X = X[X[:, 2] > 10]

# 2. 房价过滤
expensive_y = y[y > 200]

print("老房子特征:\n", old_house_X)
print("豪宅价格:", expensive_y)
```

**解析（初中生版）：**
- **布尔索引**就像老师拿着一张名单打勾（True）打叉（False），然后把打勾的同学叫出来。
- `X[:, 2] > 10` 生成 `[False, True, False, True]`，意思是第 1 套和第 3 套房子符合条件。
- 把这张“对错表”塞进方括号 `X[ ... ]`，NumPy 就自动把 True 对应的行选出来。
</details>

### 练习题 4：特征缩放——Min-Max 归一化

**场景故事：**
在机器学习中，不同特征数值范围差异很大（比如面积是 60~200，卧室数是 1~4）。如果不处理，AI 会误以为“面积”比“卧室数”重要几百倍。所以需要**归一化**，把所有特征压缩到 0~1 之间。

**公式：**
`X_norm = (X - X_min) / (X_max - X_min)`

**任务要求：**
对 `X` 数组的**面积列**（第 0 列）进行归一化处理，结果保留 2 位小数。**必须使用向量化计算，不能用循环。**

```python
# X 已存在

# ========== 你的代码在这里 ==========
area_col = None           # 提取面积列
area_min = None           # 计算最小值
area_max = None           # 计算最大值
area_norm = None          # 套公式计算
# ===================================

print("原始面积:", area_col)
print("归一化后:", area_norm)
```

<details>
<summary><b>✅ 点击查看答案与解析</b></summary>

```python
# 答案代码
area_col = X[:, 0]
area_min = area_col.min()          # 60
area_max = area_col.max()          # 200

area_norm = (area_col - area_min) / (area_max - area_min)
area_norm = np.round(area_norm, 2)  # 保留两位小数

print("原始面积:", area_col)
print("归一化后:", area_norm)
# 预期输出：[0.43, 0.18, 1.0, 0.0] (具体小数取决于计算)
```

**解析（初中生版）：**
- 归一化就像把不同大小的气球吹成一样大的比例。60 平米是这里最小的，变成 0；200 平米是最大的，变成 1；中间的按比例折算。
- **`.min()` 和 `.max()`** 是数组自带的方法，一下子就知道全班最高分和最低分。
- **向量化**：`area_col - area_min` 这一句，就把整列数据同时减去了 60，不用写 for 循环。
</details>

### 练习题 5：计算误差（MAE 平均绝对误差）

**场景故事：**
你的房价预测 AI 给出了一个预测结果。你需要计算它预测得准不准。常用的指标是 **MAE（平均绝对误差）**，公式是：`( |预测1-真实1| + |预测2-真实2| + ... ) / 样本数`。

**任务要求：**
已知真实房价 `y_true = np.array([350, 180, 620, 90])`，AI 预测的房价 `y_pred = np.array([320, 200, 600, 120])`。计算 MAE。

```python
y_true = np.array([350, 180, 620, 90])
y_pred = np.array([320, 200, 600, 120])

# ========== 你的代码在这里 ==========
mae = None   # 提示：相减 -> 取绝对值 -> 求平均
# ===================================

print("平均绝对误差 MAE:", mae)
```

<details>
<summary><b>✅ 点击查看答案与解析</b></summary>

```python
# 答案代码
mae = np.mean(np.abs(y_true - y_pred))
# 分步计算：
# 1. y_true - y_pred = [30, -20, 20, -30]
# 2. np.abs(...) = [30, 20, 20, 30]
# 3. np.mean(...) = (30+20+20+30) / 4 = 25.0

print("平均绝对误差 MAE:", mae)  # 输出 25.0
```

**解析（初中生版）：**
- **误差**就是“猜的”减去“真实答案”。
- 因为可能猜大也可能猜小，负数没意义，所以用 `np.abs()` 取绝对值（距离只看长度不看方向）。
- 最后用 `np.mean()` 算一下平均差了多少万。这里平均差 25 万，说明 AI 模型还有待提高。
</details>

### 练习题 6：批量计算预测值（线性回归公式应用）

**场景故事：**
在机器学习中，最简单的预测公式是 **线性回归**：`预测价 = 面积×w1 + 卧室×w2 + 房龄×w3 + 偏置b`。
假设经过训练，AI 已经学会了这样一组参数（权重）：
`w = [2.5, 10, -1]`，偏置 `b = 30`。

**任务要求：**
用**矩阵乘法（点积）** 一次性算出所有 4 套房子的预测价格，不要用循环。

**数学提示：**
`预测向量 = X @ w + b` （`@` 是矩阵乘法符号）

```python
X = np.array([[120, 3, 5],
              [85, 2, 20],
              [200, 4, 2],
              [60, 1, 40]])
w = np.array([2.5, 10, -1])
b = 30

# ========== 你的代码在这里 ==========
y_pred_new = None   # 提示：X 乘 w，然后加 b
# ===================================

print("预测房价:", y_pred_new)
```

<details>
<summary><b>✅ 点击查看答案与解析</b></summary>

```python
# 答案代码
y_pred_new = X @ w + b
# 或者使用 np.dot(X, w) + b

print("预测房价:", y_pred_new)
# 计算过程验证（第一套房）：
# 120*2.5 + 3*10 + 5*(-1) + 30 = 300 + 30 - 5 + 30 = 355
```

**解析（初中生版）：**
- **`@` 符号**是 NumPy 专门用来做矩阵乘法的“咒语”。
- `X` 是 4x3 的桌子，`w` 是 3x1 的柱子，乘完之后变成 4x1 的结果。
- 每一行房子数据自动和 `w` 的对应位置相乘再相加（加权求和），这就是 AI 做“心算”的过程。
- 最后加上 `b`（基础分），利用**广播**功能，自动加到每个结果上。
</details>

### 练习题 7：随机打乱数据集（Shuffle）

**场景故事：**
训练 AI 时，如果数据是按顺序排列的（比如先看了 100 张猫图再看 100 张狗图），AI 容易变傻。我们需要**随机打乱**数据的顺序，同时保证**特征 X 和标签 y 的行依然一一对应**。

**任务要求：**
生成一个随机的排列索引，然后用它同时打乱 `X` 和 `y`。
**Hint：** 使用 `np.random.permutation(n)` 生成 0 到 n-1 的随机排列。

```python
np.random.seed(42)  # 固定随机结果，方便对答案
X = np.array([[120, 3, 5],
              [85, 2, 20],
              [200, 4, 2],
              [60, 1, 40]])
y = np.array([350, 180, 620, 90])

# ========== 你的代码在这里 ==========
n_samples = X.shape[0]      # 样本个数
shuffle_idx = None          # 生成随机索引
X_shuffled = None           # 打乱 X
y_shuffled = None           # 打乱 y
# ===================================

print("打乱后的索引顺序:", shuffle_idx)
print("打乱后 X:\n", X_shuffled)
print("打乱后 y:", y_shuffled)
```

<details>
<summary><b>✅ 点击查看答案与解析</b></summary>

```python
np.random.seed(42)
X = np.array([[120, 3, 5],
              [85, 2, 20],
              [200, 4, 2],
              [60, 1, 40]])
y = np.array([350, 180, 620, 90])

# 答案代码
n_samples = X.shape[0]                 # 结果是 4
shuffle_idx = np.random.permutation(n_samples)  # 例如 [2, 0, 3, 1]
X_shuffled = X[shuffle_idx]            # 按照新顺序取行
y_shuffled = y[shuffle_idx]            # 用同样的顺序取标签

print("打乱后的索引顺序:", shuffle_idx)
print("打乱后 X:\n", X_shuffled)
print("打乱后 y:", y_shuffled)
```

**解析（初中生版）：**
- `permutation` 就像体育老师手上拿着写有学号 `[0,1,2,3]` 的纸条，放进帽子里摇一摇，倒出来的顺序是乱的，比如 `[2,0,3,1]`。
- **关键点**：`X[shuffle_idx]` 和 `y[shuffle_idx]` 用的是**同一张乱序纸条**，这样房子和它的价格还是配对的，不会把别墅的价格安到茅草屋上。
</details>
